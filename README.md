## GoldPay

架空の事業者向けオンライン決済サービスを紹介する、1ページ構成のWeb制作ポートフォリオです。

HTML / CSS / JavaScriptを使用し、サービス紹介ページとして制作しました。

※実際の決済、申込み、個人情報の送信機能は実装していません。

## 使用技術

- HTML5
- CSS3
 - Flexbox
 - CSS Grid
 - レスポンシブデザイン
- JavaScript
 - ハンバーガーメニュー
 - FAQアコーディオン
 - フッターロゴクリック時のページトップへのスムーズスクロール

## 使用ツール

- Visual Studio Code
- Google Chrome
- GitHub 
- SourceTree

## アピールポイント

- セマンティックHTMLを意識したページ構成
- Flexbox / CSS Gridを使用したレイアウト
- PC・スマートフォンに対応したレスポンシブデザイン
- JavaScriptによるハンバーガーメニューの実装
- JavaScriptによるFAQアコーディオンの実装
- CSSによる図形や装飾を活用し、外部画像素材への依存を抑えた制作

## ファイル構成

```text
.
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── assets/
    └── images/  # 画像素材を格納。現在は未使用。.gitkeepは空フォルダをGit管理に含めるために作成。
```

## 確認方法

`index.html` をブラウザで開いてください。スマートフォン幅では、右上のメニューボタンとFAQの開閉を確認できます。

## 開発の進め方
- サイトのコンセプトやページ構成、ビジュアル面の検討にAIを制作補助として活用しました。
- 提案された内容をそのまま使用するのではなく、サイトの目的や案件要件に合うか確認し、必要に応じて内容やデザインを調整しました。
- 実装内容については、理解が不十分な個所を確認しながら修正・調整を行いました。

- 制作途中からGitHub・SourceTreeによるバージョン管理を導入しました。

## 使用素材について

本サイトでは、有料素材・写真素材・生成画像を使用していません。
メインビジュアル、ロゴ、カード、グラフ風の装飾は、CSSによる図形・レイアウトと文字記号を組み合わせて制作しています。
フォントには、Google Fontsで提供されている無料フォント「DM Sans」「Noto Sans JP」を使用しています。
